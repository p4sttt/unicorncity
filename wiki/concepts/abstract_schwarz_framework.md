# Абстрактная теория Шварца

## Definition

**Абстрактная теория Шварца** (Дрыя–Уидлунд, 1989) — рамка, в которой DD-алгоритм
описывается не геометрией, а **разложением конечноэлементного пространства** на сумму
подпространств

$$
V^h = V_0 + V_1 + \dots + V_N
$$

и набором проекторов $P_i: V^h \to V_i$, определённых энергетически:

$$
a(P_i v, \varphi) = a(v, \varphi) \quad \forall \varphi \in V_i
$$

Аддитивный алгоритм — это решение системы $Pu_h = g'_h$ с $P = P_1 + \dots + P_N$ методом
сопряжённых градиентов ($P$ симметричен и положительно определён относительно
$a(\cdot,\cdot)$). Мультипликативный алгоритм — итерация с оператором распространения
ошибки $(I - P_N)\cdots(I - P_1)$.

Ключевой результат рамки: **и overlapping-, и non-overlapping-методы попадают в неё**.
Итерационное substructuring оказывается аддитивным Шварцем с другим выбором подпространств
([[dryja_widlund_unified_theory]], §5).

## Intuition

Метод полностью задан **набором подпространств** — не сеткой, не типом элемента, не тем,
какие именно локальные задачи решаются. Это позволяет анализировать разнородные алгоритмы
одним аппаратом и отвечает на вопрос «почему вообще этот метод сходится» одинаково для
всех.

Оценка $\kappa(P)$ распадается на две независимые половины:

- **Сверху** — тривиально $N$ (сумма $N$ проекторов), но улучшается до **числа цветов**
  графа пересечений подпространств: подпространства одного цвета взаимно ортогональны и
  могут рассматриваться как одно. Для типичного 2D substructuring $\lambda_{\max}(P) \le 4$.
- **Снизу** — через **константу устойчивого разложения** $C_0^2$.

## Formal description

**Лемма (устойчивое разложение; Дрыя–Уидлунд, вдохновлена Лионсом).**
Пусть $u_h = \sum_i u_{h,i}$, $u_{h,i} \in V_i$. Если разложение можно выбрать так, что

$$
\sum_i a(u_{h,i}, u_{h,i}) \le C_0^2\, a(u_h, u_h) \qquad \forall u_h \in V^h,
$$

то $\lambda_{\min}(P) \ge C_0^{-2}$.

Отсюда

$$
\kappa(P) \le (\text{число цветов}) \cdot C_0^2
$$

Замечание, важное на практике: **расширение подпространств может только улучшить $C_0$**
(больше свободы в выборе разложения), но делает локальные подзадачи крупнее и хуже
обусловленными. Это и есть компромисс «ширина наложения ↔ стоимость локального решения».

**Замена точных локальных решателей приближёнными.** Если $K_{(i)}^{-1}$ заменить на
$\hat{K}_{(i)}^{-1}$, то

$$
\kappa(\hat{P}) \le
\left[
\frac{\max_i \lambda_{\max}(K_{(i)}\hat{K}_{(i)}^{-1})}
{\min_i \lambda_{\min}(K_{(i)}\hat{K}_{(i)}^{-1})}
\right] \cdot \kappa(P)
$$

то есть анализ предобусловленного варианта сводится к анализу базового плюс качество
локальных решателей — отдельно и независимо. Это одна из самых полезных черт рамки.

## Основные результаты в этой рамке

| алгоритм | подпространства | оценка |
|---|---|---|
| Аддитивный Шварц с щедрым наложением + грубая сетка | $V^H + H^1_0(\Omega'_i) \cap V^h$ | $\kappa(P) \le \text{const}$ |
| То же, наложение $\sim$ квадратично меньше | | $\kappa(P) \le C(1 + \log(H/h))$ |
| 2D substructuring по рёбрам | $V^H + H^1_0(\Omega_{ij}) \cap V^h$ | $\kappa(P) \le C(1 + \log(H/h))^2$ |
| Без грубого пространства (только соседи) | $V_1 + \dots + V_N$ | $\kappa \gtrsim 1/H^2$ |

Последняя строка — нижняя оценка Уидлунда: **любой** DD-метод, где взаимодействие идёт
только через соседние подобласти, имеет $\kappa$, растущее не медленнее $1/H^2$. Это
формальное обоснование необходимости грубого уровня: [[coarse_spaces_two_level_methods]].

Константа в оценках $(1 + \log(H/h))^2$ не зависит от $h$, $H$ **и от разрывов коэффициента
$\rho(x)$**, если разрывы выровнены по границам подструктур. Если нет — вопрос открыт до сих
пор.

## Что рамка даёт и чего не даёт

**Даёт.** Единый язык; развязку «геометрия ↔ локальные решатели»; готовый рецепт
доказательства (построил разложение — получил оценку); объяснение, почему грубое
пространство необходимо, а не просто полезно.

**Не даёт.** Мультипликативный случай для более чем двух подпространств проработан
существенно хуже аддитивного. Также рамка предполагает симметричную, самосопряжённую
задачу; расширения на несимметричные и знаконеопределённые задачи (Cai, Mathew) идут
отдельно и с оговорками.

## Развитие: от неравенства к тождеству

Оценка $\lambda_{\min}(P) \ge C_0^{-2}$ впоследствии оказалась не оценкой, а половиной
тождества. Для аддитивной версии энергия предобусловливателя выражается точно:
$\langle B_a^{-1}v, v\rangle = \inf_{\sum v_i = v} \sum_i \langle R_i^{-1}v_i, v_i\rangle$,
то есть $C_0^2$ — само значение этой энергии, а не артефакт техники доказательства. Для
мультипликативной версии, которую рамка Дрыи–Уидлунда оставила недоработанной, точный ответ
даёт тождество Сюя–Зикатанова (2002), а для двухуровневого случая — двухсеточное тождество
Фалгаута–Василевски–Зикатанова. Всё это изложено в [[multigrid_general_theory]]; там же
показано, что многосеточный V-цикл есть последовательная коррекция по вложенной цепочке
подпространств, то есть частный случай той же рамки.

## Развитие: спектрально порождённые грубые пространства

Логика Дрыи–Уидлунда «построй разложение → получи $C_0$». Современный поворот
([[subspace_uzawa_two_grid]], GenEO) переворачивает направление: **назови желаемую
константу $\tau$, и локальные обобщённые задачи на собственные значения сами скажут,
сколько грубых функций нужно на каждом патче**. $C_{\mathrm{stab}}$ становится величиной,
которую задают, а не которая получается. Оценка при этом обращается в тождество:
$\lambda_{\max}(BA) = 1$, $\lambda_{\min}(BA) = 1/C_{\mathrm{stab}}$, то есть
$\kappa(BA) = \max(1, C_{\mathrm{stab}})$ без константы спереди.
