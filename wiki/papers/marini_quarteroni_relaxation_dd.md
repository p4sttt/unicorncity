# A Relaxation Procedure for Domain Decomposition Methods Using Finite Elements

L. D. Marini (IAN CNR, Pavia), A. Quarteroni (Università Cattolica, Brescia).
Numerische Mathematik 55, 575–598 (1989).

## TL;DR

Анализ сходимости итерационной DD-схемы, где условия сопряжения на интерфейсе учитываются
**частично в одной подобласти и частично в соседней**, а на интерфейсе применяется
релаксация с параметром $\theta$. Никакого глобального предобусловливателя не требуется —
только стандартные одно-доменные FEM-решатели. Главные результаты: интервал
$(0, \theta^*)$, в котором схема сходится; **фактор уменьшения ошибки за итерацию не зависит
от шага сетки $h$**; явная формула оптимального $\theta$ и построенная на ней автоматическая
динамическая стратегия. Метод переносится на несжимаемые уравнения Стокса.

## Core contribution

Альтернатива подходу «собрать глобальную систему на интерфейсе + подобрать
предобусловливатель». Здесь используется принцип эквивалентности между одно-доменной и
многодоменной формулировкой краевой задачи второго порядка, откуда получается итерация по
подобластям, дающая последовательность обычных одно-доменных краевых задач: в одной
подобласти навязывается непрерывность решения, в другой — непрерывность нормальной
производной в слабом смысле. В пределе оба условия сопряжения выполнены.

## Method

### Расщепление (лемма 2.1)

$u$ решает исходную задачу тогда и только тогда, когда $u_1 = u|_{\Omega_1}$,
$u_2 = u|_{\Omega_2}$ удовлетворяют

$$
\begin{aligned}
&a_1(u_1, v) = (f, v)_1 \quad \forall v \in V_1^0, \qquad u_1 = u_2 \ \text{на } \Gamma
&& \text{(Дирихле)} \\
&a_2(u_2, v) = (f, v)_2 - a_1(u_1, R_1\gamma_0 v) + (f, R_1\gamma_0 v)_1
\quad \forall v \in V_2 && \text{(смешанная)}
\end{aligned}
$$

где $R_1$ — оператор продолжения с $\Gamma$ на $\Omega_1$, $\gamma_0$ — след. Интегрирование
по частям показывает, что вторая — вариационная формулировка смешанной задачи с условием на
поток.

### Итерация с релаксацией

$$
\begin{aligned}
a_1(u_1^n, v) &= (f, v)_1, \qquad \gamma_0 u_1^n = g^{n-1} \ \text{на } \Gamma \\
a_2(u_2^n, v) &= (f, v)_2 - a_1(u_1^n, R_1\gamma_0 v) + (f, R_1\gamma_0 v)_1 \\
g^n &= \theta_n \gamma_0 u_2^n + (1 - \theta_n) g^{n-1}
\end{aligned}
$$

$\theta_n > 0$ — параметр релаксации, подлежащий определению.

### Анализ

Вводится оператор $T_\theta \psi = \theta T\psi + (1 - \theta)\psi$ на пространстве следов
$\Phi = H^{1/2}_{00}(\Gamma)$ с нормой $\|\psi\|^2_\Phi = \|R_1\psi\|^2_1$. Через две
константы, сравнивающие эквивалентные нормы $\|R_1\varphi\|_1$ и $\|R_2\varphi\|_2$,

$$
\sigma = \sup \left\{ \frac{\|R_1\varphi\|_1^2}{\|R_2\varphi\|_2^2} \right\}, \qquad
\tau = \sup \left\{ \frac{\|R_2\varphi\|_2^2}{\|R_1\varphi\|_1^2} \right\}
$$

получается оценка

$$
\|T_\theta \psi\|^2 \le
\bigl( \theta^2(\sigma^2\tau + \tau + 2) - 2\theta(\tau + 1) + \tau \bigr)
\cdot \frac{\|\psi\|^2}{\tau}.
$$

## Key results

- **Теорема 3.1.** Существует $\theta^* \in (0,1]$ такое, что для всех
  $\theta \in (0, \theta^*)$ оператор $T_\theta$ — сжатие:
  $\exists\, k(\theta) < 1$ с $\|T_\theta\psi\| \le k(\theta)\|\psi\|$.
- **Теорема 3.2.** Если $\theta_{\min} \le \theta_n \le \theta^*$ для всех $n$, вся
  последовательность сходится.
- **Оптимальный $\theta$ (замечание 3.1).** Дифференцирование оценки даёт

  $$
  \theta_{\mathrm{opt}} = \frac{\tau + 1}{\sigma^2\tau + \tau + 2}, \qquad
  k(\theta_{\mathrm{opt}}) = \frac{\sigma^2\tau^2 - 1}{\tau(\sigma^2\tau + \tau + 2)}
  $$

  Отсюда следует, что **$k(\theta_{\mathrm{opt}}) = 0$ тогда и только тогда, когда
  $\sigma\tau = 1$**, что происходит, например, при $\Omega_1 = \Omega_2$ — в этом случае
  схема сходится **ровно за два шага**. Тогда же $\sigma = \tau = 1$ и $\theta^* = 1$, и
  условие $0 < \theta < \theta^* = 1$ оказывается необходимым для сходимости при
  произвольном начальном приближении.
- **Замечание 3.2: несамосопряжённый случай.** Результат типа (3.16) сохраняется, если
  антисимметричная часть оператора не слишком велика: при $M\sigma < 1$ схема сходится для
  всех $\theta \in (0,1)$; при $M\sigma > 1$ требуется дополнительно $\beta < 2$ ($M$ —
  константа непрерывности $a_1$).
- **Теоремы 4.1, 4.2: конечноэлементный случай.** Фактор уменьшения ошибки $K$
  **не зависит от шага сетки $h$** (замечание 4.4) — то есть метод оптимален в этом смысле.
- **Автоматический выбор $\theta$ (§5).** Из доказательства сходимости следует динамическая
  стратегия: последовательность
  $\theta_n = (\tau_n + 1)/(\sigma^2\tau_n + \tau_n + 2)$, вычисляемая **без дополнительной
  стоимости** из уже посчитанных на итерации решений, сходится к $\theta_{h,\mathrm{opt}}$.
  Инициализация требует решения 4 задач, каждая последующая итерация — только 2.
- **Матричная интерпретация (§5.1).** Схема эквивалентна
  $\xi^{(n+1)} = \theta_n S_2^{-1}\bigl(d - S_1\xi^{(n)}\bigr) + (1 - \theta_n)\xi^{(n)}$,
  то есть либо SUR-методу для расщепления $S = S_2 - (-S_1)$, либо **методу Ричардсона с
  $S_2$ в качестве предобусловливателя**. Это тесно связывает работу с подходом
  Бьёрстада–Уидлунда, где та же система решается CG с предобусловливателем $S_2$; спектр
  $S_2^{-1}S$ не зависит от $h$.
- **§6: уравнения Стокса.** Тот же аппарат переносится на несжимаемые уравнения Стокса
  (теорема 6.1); нужна лемма об эквивалентности норм для оператора Стокса, аналог леммы 4.1.

### Численные результаты (§5.2)

Задача Пуассона $\Delta u = 0$, $u = 1$ на $\partial\Omega$ (точное решение и его
кусочно-линейная FE-аппроксимация тождественно равны 1), случайный старт, две области,
каждая на две подобласти. $n$ — минимум итераций для уменьшения начальной ошибки в $10^5$
раз, erf — средний фактор уменьшения:

| область | $N=15$ | $N=77$ | $N=345$ |
|---|---|---|---|
| первая | $n=3$, erf $=0.007$ | $n=3$, erf $=0.019$ | $n=4$, erf $=0.036$ |
| | **$N=85$** | **$N=297$** | **$N=1105$** |
| вторая | $n=4$, erf $=0.02$ | $n=5$, erf $=0.069$ | $n=5$, erf $=0.09$ |

Рост числа итераций с увеличением $N$ на порядок — на 1–2 итерации. Для оператора Гельмгольца
$\Delta u - \lambda u$ ($\lambda < 0$) результаты, по словам авторов, даже лучше.

## Limitations

- Теория сходимости выведена для разбиения на **две** подобласти; интервал сходимости для
  $\theta$ найден именно там.
- Обобщение на несамосопряжённый случай требует, чтобы антисимметричная часть была «не
  слишком существенна» относительно симметричной — условие (3.36) с $\beta < 2$. Авторы
  утверждают, что это естественно в данном контексте.
- Замечание 5.1: если использовать Ричардсон с минимально-невязочной стратегией выбора
  $\theta_n$, ни $S$, ни $S_2$ не обязаны быть симметричны — достаточно, чтобы симметричная
  часть $S_2^{-1}S$ имела положительные собственные значения. Это ровно эквивалентно (3.36)
  при $\beta < 2$.

## My notes

Самое практически ценное здесь — **автоматический $\theta$**. В бенчмарках
[[scherbakov_rakhimov_classic_iterative_methods]] стационарный Ричардсон с фиксированным
$\tau$ демонстрирует ровно то, от чего эта статья избавляет: при $\tau = 10^{-3}$ итерация
после 16 384 шагов остаётся на восемь порядков дальше от допуска. Современный ответ —
заменить стационарную итерацию на PCG/GMRES; ответ 1989 года — вычислять оптимальный
$\theta_n$ на лету из уже посчитанных величин. Второй путь дешевле и в матричной
интерпретации (5.21) виден как то же самое: Ричардсон с $S_2$ в качестве
предобусловливателя, у которого шаг подбирается адаптивно.

Наблюдение $k(\theta_{\mathrm{opt}}) = 0$ при $\sigma\tau = 1$ (симметричные подобласти
$\to$ сходимость за два шага) — хорошая проверка интуиции: если задача симметрична
относительно интерфейса, оператор Пуанкаре–Стеклова каждой половины даёт ровно половину
полного, и $S_2$ становится точным предобусловливателем.
