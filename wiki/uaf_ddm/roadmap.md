# Roadmap проекта UAF-DDM

## Фаза 1: Теоретический фундамент

- [x] **Алгебра примитивов**: Единый язык ($R_i, D_i, \mathcal{S}_i, \mathcal{S}_0, \mathcal{K}$) для описания DDM как DAG.
- [x] **Derivation Engine**: 3-шаговая процедура вывода $\kappa$ из структуры графа ($\lambda_{max}$ → $\lambda_{min}$ → $N_{iter}$).
- [x] **Исправление оценок $\kappa$**: Block Jacobi ($O((H/h)^2)$), 1-Level AS ($O(H^2/(\delta h))$), ORAS ($O(\sqrt{H/h})$).
- [x] **Формализация async trade-off**: Теорема Chazan–Miranker, пороговый критерий $\tau_{nat} < L_{sync}/T_{comp}$.
- [x] **Разделение математики и инженерии**: Kernel Fusion вынесен из теории в Cost Model.
- [ ] **Расширение Абстрактного Шварца**: Ввести гильбертово пространство с нормой стоимости (cost norm), где $\|u\|_\mathcal{C}$ отражает затраты на применение проектора $P_i u$.
- [ ] **Топология железа**: Формализовать аппаратный граф $\mathcal{H}$ в терминах графа перекрытий подпространств.
- [ ] **Формулировка SDP**: Записать поиск оптимальной декомпозиции как задачу полуопределенного программирования (Semi-Definite Programming).

## Фаза 2: Proof of Concept на модельных задачах

- [x] **1D Пуассон**: Аналитическое решение $N^* = (n\pi/\beta)^{1/4}$ с проверкой предельных случаев.
- [ ] **2D Poisson с checkerboard контрастом**: Аналитическое решение, демонстрация влияния GenEO.
- [ ] Сравнение аналитического экстремума с известными границами BDDC и FETI-DP.
- [ ] Демонстрация того, что при $T_{comm} \to \infty$ функционал выбирает метод с нулевым наложением (substructuring), а при $T_{coarse\_cost} \to \infty$ отказывается от двухуровневого метода.

## Фаза 3: Auto-DDM MVP

- [ ] Написание Python/JAX фреймворка, который принимает конечноэлементную сборку и профиль железа, решает релаксированную задачу оптимизации и компилирует оптимальный решатель.
- [ ] Интеграция с существующими JAX DDM-солверами (опираясь на [[scherbakov_rakhimov_classic_iterative_methods]]).

## Риски

| Риск | Митигация |
|---|---|
| Пространство $\mathbb{G}$ дискретное → NP-трудная оптимизация | Начать с непрерывной SDP-релаксации, затем округлять |
| Спектральные coarse spaces (GenEO) требуют eigenvalue estimates | Использовать bounds из GenEO теории (Spillane et al. 2014) |
| Kernel Fusion для произвольных DAG — нерешённая проблема компиляторов | Начать с шаблонов для типовых топологий (аддитивная, 2-level) |
