# UAF-DDM: Вывод оценок алгоритмов

В данном документе 19 классических и современных методов декомпозиции области описаны строго через алгебру UAF-DDM. Для каждого метода дано формальное описание, граф вычислений $\mathcal{G}$, и строгий аналитический вывод числа обусловленности $\kappa$ и функции стоимости $Cost_{total}$.

---

## 1. Block Jacobi (Zero-Overlap AS)

**Формальное описание**: Метод без перекрытия. Пространство разбивается на независимые непересекающиеся подобласти. На каждой итерации решаются локальные задачи Дирихле без обмена интерфейсными узлами.
**Граф $\mathcal{G}$**: $\mathcal{P}^{-1} = \sum_{i=1}^N R_i^T \mathcal{S}_i R_i$

**Оценка $\kappa$**:
*   $\lambda_{max} \le \rho(\mathcal{E}) + 1 = 1$ (ортогональные непересекающиеся подпространства).
*   $\lambda_{min}$: Без грубого пространства stable decomposition не гарантируется для глобальных мод. Для задачи Дирихле дискретное неравенство Пуанкаре на подобласти даёт $C_0^2 = O\left(\left(\frac{H}{h}\right)^2\right)$, следовательно $\lambda_{min} = O\left(\left(\frac{h}{H}\right)^2\right)$.
*   $\kappa = O\left(\left(\frac{H}{h}\right)^2\right) = O(n_i)$. Растёт линейно с числом DOF в подобласти (Dryja 1991, Smith–Bjørstad–Gropp 1996, §3.1).

**Оценка Стоимости**:
*   $T_{setup} = N_{loc}^{1.5}/\pi$ (LU факторизация локальных блоков).
*   $T_{step} = N_{loc}/\beta + L_{sync}$ (отсутствует коммуникация $\to L_{net}=0$).
*   $Cost_{total} = \frac{N_{loc}^{1.5}}{\pi} + O\left(\frac{H}{h}\right) \cdot \ln(2/\epsilon) \times T_{step}$ (плохая масштабируемость, но метод формально сходится для задач Дирихле).

---

## 2. 1-Level Additive Schwarz (AS)

**Формальное описание**: Метод с перекрытием $\delta$. Подобласти расширяются на соседние узлы. Решения на перекрытиях суммируются.
**Граф $\mathcal{G}$**: $\mathcal{P}^{-1} = \sum_{i=1}^N R_{i,\delta}^T \mathcal{S}_i R_{i,\delta}$

**Оценка $\kappa$**:
*   $\lambda_{max} \le N_c \le 4$ (для 2D сетки максимальное число соседей + сам домен).
*   $\lambda_{min}$: Оценка градиента разбиения единицы $|\nabla \theta_i| \leq C/\delta$. Без грубого пространства $L^2$-компонента не контролируется; через обратное неравенство $\|u\|^2 \leq Ch^{-2}\|u\|_a^2$, получаем $C_0^2 = O\left(\frac{H}{\delta} \cdot \frac{H}{h}\right)$.
*   $\kappa = O\left(\frac{H^2}{\delta h}\right)$. Не масштабируется (зависит от $h$) — именно поэтому необходим 2-й уровень (Dryja & Widlund 1994, Toselli & Widlund 2005, §3.1).

**Оценка Стоимости**:
*   $T_{setup} = N_{loc,\delta}^{1.5}/\pi$.
*   $T_{step} = N_{loc,\delta}/\beta + \frac{|\text{Halo}|}{\beta} + L_{sync} + L_{net}$.
*   $Cost_{total} = T_{setup} + \lceil \frac{\sqrt{\kappa}}{2} \ln(2/\epsilon) \rceil \times T_{step}$.

---

## 3. Restricted Additive Schwarz (RAS)

**Формальное описание**: Модификация AS, где извлечение вектора невязки (Restriction) делается с перекрытием, а подъем решения (Prolongation) — без него.
**Граф $\mathcal{G}$**: $\mathcal{P}^{-1} = \sum_{i=1}^N \tilde{R}_{i,0}^T \mathcal{S}_i R_{i,\delta}$

**Оценка $\kappa$**:
*   Оператор несимметричен, классический спектр неприменим. Но спектральный радиус матрицы итераций сжимается за счет исключения дублирования на перекрытиях. Сходится быстрее AS.

**Оценка Стоимости**:
*   $T_{setup} = N_{loc,\delta}^{1.5}/\pi$.
*   $T_{step} = \frac{1}{2} \frac{|\text{Halo}|}{\beta} + L_{sync} + L_{net}$ (в два раза меньше пересылок).
*   $Cost_{total}(RAS) < Cost_{total}(AS)$.

---

## 4. Multiplicative Schwarz (MS)

**Формальное описание**: Последовательное применение локальных решателей (аналог Гаусса-Зейделя), где каждый следующий домен использует уже обновленные данные соседей.
**Граф $\mathcal{G}$**: Оператор ошибки $E = \prod_{i=1}^N (I - R_i^T \mathcal{S}_i R_i A)$

**Оценка $\kappa$**:
*   $\lambda_{max} = 1$ (строго).
*   $\lambda_{min}$ аналогична AS. Сходится ровно в 2 раза быстрее AS по итерациям.

**Оценка Стоимости**:
*   $T_{setup} = N_{loc,\delta}^{1.5}/\pi$.
*   $T_{step} = N_c \times \left( N_{loc,\delta}/\beta + L_{net} + L_{sync} \right)$ (последовательность кратна числу цветов графа).
*   $Cost_{total} \gg Cost_{total}(AS)$ для GPU из-за огромного $L_{sync}$.

---

## 5. Two-Level Additive Schwarz (AS-2)

**Формальное описание**: AS с добавлением глобальной задачи на грубой сетке (один узел на подобласть).
**Граф $\mathcal{G}$**: $\mathcal{P}^{-1} = R_0^T \mathcal{S}_0 R_0 + \sum_{i=1}^N R_i^T \mathcal{S}_i R_i$

**Оценка $\kappa$**:
*   $\lambda_{max} \le N_c + 1$.
*   $\lambda_{min}$: $R_0$ покрывает ядро (константы). Применяем локальное неравенство Фридрихса. $C_0^2 = 1 + \frac{H}{\delta}$.
*   $\kappa = O(1 + H/\delta)$ (Масштабируемо, не зависит от $N$).

**Оценка Стоимости**:
*   $T_{setup} = N_{loc}^{1.5}/\pi + N_{sub}^3/\pi$.
*   $T_{step} = T_{local} + (N_{sub}^2/\pi + L_{net} \log N)$.
*   $Cost_{total} = \dots$ (Асимптотически доминирует $\mathcal{S}_0$ при $N \to \infty$).

---

## 6. Neumann-Neumann (NN)

**Формальное описание**: Метод без перекрытия. Решается задача Дирихле в доменах, затем вычисляется скачок потоков (Нейман) на интерфейсе, который усредняется с весами.
**Граф $\mathcal{G}$**: $\mathcal{P}^{-1} = \sum_{i=1}^N D_i R_i^T \mathcal{S}_{\text{Schur},i}^{-1} R_i D_i$

**Оценка $\kappa$**:
*   $\lambda_{max} \le 4$.
*   $\lambda_{min}$: Лемма о следах для $\mathcal{S}_{\text{Schur}}$ дает константу $\frac{1}{H} \frac{1}{h}$.
*   $\kappa = O(H^{-2} h^{-1})$.

**Оценка Стоимости**:
*   $T_{setup} = 2 \times N_{loc}^{1.5}/\pi$ (расчет матрицы Шура).
*   $T_{step} = T_{Schur} + 2 L_{net}$.

---

## 7. Balancing Domain Decomposition (BDD)

**Формальное описание**: Двухуровневый NN. Интерфейсная задача балансируется проекцией на нулевое пространство жестких мод.
**Граф $\mathcal{G}$**: $\mathcal{P}^{-1} = R_0^T \mathcal{S}_0 R_0 + (I - P_0) \left( \sum_{i=1}^N D_i R_i^T \mathcal{S}_i R_i D_i \right) (I - P_0)$

**Оценка $\kappa$**:
*   $\lambda_{max} \le 4$.
*   $\lambda_{min}$: Оценка через теорему продолжения. $C_0^2 = (1 + \log(H/h))^2$.
*   $\kappa = O((1 + \log(H/h))^2)$.

**Оценка Стоимости**:
*   Проекторы добавляют $+ 2 \times L_{net}$ за итерацию (дорого!).

---

## 8. FETI-1 (1-Level Dual)

**Формальное описание**: Область разрывается. Сплошность обеспечивается множителями Лагранжа. Решаются локальные задачи Неймана.
**Граф $\mathcal{G}$**: $\mathcal{P}^{-1} = \sum_{i=1}^N B_i \mathcal{S}_{i}^{\dagger} B_i^T$

**Оценка $\kappa$**: $\kappa = O(H^{-2} h^{-1})$ (Аналогично NN).
**Оценка Стоимости**: Дороже из-за псевдообращения $\mathcal{S}_{i}^{\dagger}$ для сингулярных локальных задач (свободное плавание подобластей).

---

## 9. FETI-DP (Dual-Primal)

**Формальное описание**: Угловые узлы (primal) остаются сшитыми глобально и образуют $\mathcal{S}_0$. Ребра (dual) разрываются.
**Граф $\mathcal{G}$**: Неявное слияние $\mathcal{S}_0$ и псевдоинверторов $\mathcal{S}_i$ в одну седельную систему.

**Оценка $\kappa$**:
*   Углы исключают нулевые моды $\to$ локальные задачи не сингулярны (псевдообращение не нужно).
*   $\kappa = O((1 + \log(H/h))^2)$.

**Оценка Стоимости**:
*   Исчезает проектор $(I - P_0)$, присущий BDD и FETI-1.
*   $T_{step}$ содержит только 1 глобальную редукцию. Наиболее оптимален на HPC.

---

## 10. BDDC (Primal Equivalent of FETI-DP)

**Формальное описание**: Primal-формулировка, где пространство функций ограничено непрерывностью в углах (primal constraints).
**Граф $\mathcal{G}$**: $\mathcal{P}^{-1} = R_{\Gamma}^T \left( R_{0}^T \mathcal{S}_0 R_{0} + \sum R_i^T \tilde{\mathcal{S}}_i R_i \right) R_{\Gamma}$

**Оценка $\kappa$**: Спектр изоморфен FETI-DP. $\kappa = O((1 + \log(H/h))^2)$.
**Оценка Стоимости**: Алгебраически проще собирается матрица, стоимости совпадают с FETI-DP.

---

## 11. Optimized Restricted Additive Schwarz (ORAS)

**Формальное описание**: Использование смешанных граничных условий (Robin/Impedance) на интерфейсах вместо Дирихле.
**Граф $\mathcal{G}$**: $\mathcal{P}^{-1} = \sum_{i=1}^N \tilde{R}_{i,0}^T \mathcal{S}_{\text{Robin}, i} R_{i,\delta}$

**Оценка $\kappa$**:
*   Robin-оператор $\partial_n u + pu = \ldots$ поглощает высокочастотные моды на интерфейсе, радикально улучшая $\lambda_{min}$.
*   **0-й порядок** (Robin, $p_{opt} = O(h^{-1/2}H^{-1/2})$): $\kappa_{eff} = O\left(\sqrt{H/h}\right)$.
*   **2-й порядок** (Ventcell, $\partial_n u + pu - q\Delta_\Gamma u = \ldots$): $\kappa_{eff} = O\left((H/h)^{1/4}\right)$.
*   Сравнение: RAS имеет $\kappa = O(1 + H/\delta)$ при $\delta \sim h$, т.е. $O(H/h)$. ORAS с Robin даёт $O(\sqrt{H/h})$ — **квадратный корень** улучшения. (Gander 2006, Dolean et al. 2015, Ch. 4–5.)

**Оценка Стоимости**: $T_{setup}$ немного возрастает (сборка Robin-граничных условий добавляет $O(|\Gamma_i|)$ к сборке матрицы). $T_{step}$ идентичен RAS.

---

## 12. FETI-2

**Формальное описание**: Двухуровневый FETI с глобальными множителями Лагранжа.
**Граф $\mathcal{G}$**: Вложенный итерационный цикл (внутренний CG для дуальных переменных, внешний для primal).
**Оценка Стоимости**: Мультипликативный рост $L_{net}$. Архитектурно проигрывает FETI-DP.

---

## 13. BDDC with Deluxe Scaling

**Формальное описание**: BDDC, где матрицы $D_i$ не просто диагональны, а вычисляются из решения плотных задач Шура на гранях.
**Граф $\mathcal{G}$**: $\mathcal{P}^{-1} = \sum R_{\Gamma}^T \dots D_{\text{Deluxe}} \dots$

**Оценка $\kappa$**:
*   $C_0^2$ становится независимым от контраста коэффициентов (материала).
*   $\kappa = O((1 + \log(H/h))^2)$ для ЛЮБЫХ скачков гетерогенности.

**Оценка Стоимости**:
*   Огромный рост $T_{setup}$ на решение $S_{\text{face}}^{-1}$. Окупается только на экстремально жестких задачах.

---

## 14. Algebraic Multigrid DDM (AMG-DDM)

**Формальное описание**: AS-2, где точный грубый решатель заменен на один итерационный V-цикл AMG.
**Граф $\mathcal{G}$**: $R_0^T \mathcal{S}_{\text{V-cycle}} R_0 + \sum R_{i,\delta}^T \mathcal{S}_i R_{i,\delta}$

**Оценка $\kappa$**:
*   $\lambda_{min}$ уменьшается на фактор возмущения V-цикла. Константа сходимости увеличивается.

**Оценка Стоимости**:
*   $T_{setup}(\mathcal{S}_0)$ падает с $O(N_{sub}^3)$ до $O(N_{sub})$.
*   Оптимален для Экзаскейла ($N \to 10^6$), так как решает проблему узкого горлышка $Cost(\mathcal{S}_0)$.

---

## 15. Dirichlet-Neumann (Non-overlapping)

**Формальное описание**: Итерационная передача производной и значения между двумя подобластями.
**Оценка Стоимости**: Строго мультипликативный граф $\to$ $Cost_{total}$ содержит огромный штраф $L_{sync} \times N$.

---

## 16. Asynchronous Additive Schwarz (Async-AS)

**Формальное описание**: AS, в котором локальные решатели не ждут глобальной синхронизации. Каждый поток выполняет $\mathcal{S}_i$ с теми данными от соседей, которые доступны в кэше/памяти (устаревшие на $\tau$ шагов).
**Граф $\mathcal{G}$**: $\mathcal{P}^{-1} = \sum_{i=1}^N R_{i,\delta}^T \mathcal{S}_i R_{i,\delta} (\text{delayed by } \tau_i)$

**Оценка $\kappa$**:
*   Стандартный анализ $\lambda_{min}$ ломается из-за потери симметрии оператора.
*   **Theorem (Chazan & Miranker 1969, Frommer & Szyld 2000).** Если синхронный DDM имеет спектральный радиус $\rho_0 < 1$, а асинхронный вариант допускает максимальную задержку $\tau$ шагов, то:
    $$\rho_\tau \leq \rho_0^{1/(\tau+1)}$$
*   Следствие: число итераций увеличивается в $(\tau+1)$ раз: $N_{iter}^{async} \approx (\tau+1) \cdot N_{iter}^{sync}$.

**Оценка Стоимости**:
*   $T_{setup} = N_{loc,\delta}^{1.5}/\pi$.
*   $T_{step}^{async} = N_{loc,\delta}/\beta + L_{net}$ (полностью отсутствует барьер $L_{sync}$).
*   **Критерий выгодности.** Сравнивая полные стоимости:
    - Sync: $Cost^{sync} = N_{iter} \cdot (T_{comp} + L_{sync})$
    - Async: $Cost^{async} = (\tau+1) \cdot N_{iter} \cdot T_{comp}$

    Async-DDM выгоден тогда и только тогда, когда естественная задержка $\tau_{nat} = \lceil L_{comm}/T_{comp} \rceil$ удовлетворяет:
    $$\tau_{nat} < \frac{L_{sync}}{T_{comp}}$$

---

## 17. GenEO (Generalized Eigenvalue in the Overlap)

**Формальное описание**: Двухуровневый AS, где базис пространства $R_0$ формируется не из констант, а путем решения локальных обобщенных проблем на собственные значения в перекрытиях.
**Граф $\mathcal{G}$**: $R_{GenEO}^T \mathcal{S}_0 R_{GenEO} + \sum_{i=1}^N R_i^T \mathcal{S}_i R_i$

**Оценка $\kappa$**:
*   Вывод $\lambda_{min}$ не использует неравенство Пуанкаре. Вместо этого константа стабильного разложения явно ограничивается сверху: $C_0^2 \le \frac{1}{\lambda_{tol}}$, где $\lambda_{tol}$ — порог обрезки собственных значений.
*   $\kappa = O(1 + \frac{1}{\lambda_{tol}})$. Полная независимость от $H$, $h$ и скачков коэффициентов (материала).

**Оценка Стоимости**:
*   Экстремально высокий $T_{setup}$ (требуется решать задачи на собственные значения).

## 18. Space-Time Parareal (DDM in Time)

**Формальное описание**: Декомпозиция не только по пространству, но и по времени. Совмещает грубый (быстрый) решатель по всей оси времени и точные решатели на коротких интервалах.
**Граф $\mathcal{G}$**: $\mathcal{G}_{time}$ представляет собой предиктор-корректор схему.

**Оценка $\kappa$**:
*   $\kappa \propto \frac{\Delta T}{\Delta t}$, где $\Delta T$ шаг грубого решателя, $\Delta t$ — точного.
*   Асимптотика сходится за несколько итераций при правильном выборе соотношения шагов.

**Оценка Стоимости**:
*   Позволяет параллелить интегрирование по времени, что критически важно при $N_{time} > 10^5$.

---

## 19. Lumped FETI-DP

**Формальное описание**: Упрощенная версия FETI-DP, где матрица весов (Preconditioner) диагональна (Lumped), в отличие от классического Dirichlet прекондиционера.
**Граф $\mathcal{G}$**: Аналогичен FETI-DP, но $\tilde{\mathcal{S}}_i$ заменена на матрицу жесткости без обращения.

**Оценка $\kappa$**:
*   $\lambda_{min}$: Вывод через неравенства следов показывает, что константа $C_0^2$ теперь зависит от скачков коэффициентов $O(H/h \times \max K / \min K)$.
*   $\kappa \gg \kappa(FETI-DP)$.

**Оценка Стоимости**:
*   $T_{step}$ дешевле, так как не требуется решать задачи Неймана на каждом шаге итерации. Компромисс между числом итераций и ценой шага.
