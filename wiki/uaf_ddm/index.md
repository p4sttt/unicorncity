# UAF-DDM (Unified Algebraic Framework for DDM)

## Статус-кво
Теория методов декомпозиции области разделена на два лагеря:
1. Математики доказывают оценки числа обусловленности $\kappa \le \omega C_0^2 (\rho(\mathcal{E}) + 1)$ (Абстрактный Шварц, [[dryja_widlund_unified_theory]]).
2. HPC-инженеры борются за минимизацию реального времени выполнения $T_{total} = T_{setup} + N_{iter} \times (T_{local} + T_{coarse} + T_{comm})$.

## Проблема
Уменьшение $\kappa$ через обогащение грубого пространства (например, добавление спектральных базисов) приводит к катастрофическому росту $T_{coarse}$. У нас нет математической формулы, которая аналитически связывает спектральные свойства дифференциального оператора $A$ с аппаратными таймингами графа $\mathcal{H}$.

## Точки улучшения
- Интегрировать оператор "вычислительной стоимости" $\mathcal{C}$ прямо в лемму Шварца.
- Формализовать MPI-коммуникации ($T_{comm}$) через спектральную теорию графов (расширение матрицы углов $\mathcal{E}$).
- Отделить аппаратно-зависимые оптимизации (Kernel Fusion, $L_{sync}$) от чистой математической теории в отдельный Cost Model.

## Решение
Разработать единый оптимизационный функционал $\mathcal{F}(\{V_i\}_{i=0}^N; \mathcal{H}) \to \min$, минимизация которого (например, полуопределенным программированием SDP) выдает оптимальные подпространства $\{V_i\}$ для заданного диффура и заданного суперкомпьютера. Классические методы (FETI-DP, BDDC, MS, AS) должны оказаться частными решениями этой задачи.

## Критерии успеха
- Построение аналитического функционала $\mathcal{F}$.
- Proof-of-Concept: аналитическое решение оптимизации для 1D Пуассона с формулой $N^*(\mathcal{H})$.
- Доказательство, что BDDC является экстремумом $\mathcal{F}$ при определённых допущениях на $\mathcal{H}$.
- Разработка Auto-DDM алгоритма, подбирающего параметры "на лету" без пробных запусков.
